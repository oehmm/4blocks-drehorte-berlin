# 4 Blocks Drehorte Berlin

Interaktive Karte der Berliner Drehorte der TNT-Serie *4 Blocks*: https://oehmm.github.io/4blocks-drehorte-berlin/

- Daten: `scripts/orte.py` → `scripts/build.py` (OSM-Basiskarte, Geokodierung via Nominatim)
- Fotos: Wikimedia Commons (`scripts/photos.py`), Lizenzen in der App angegeben
- Handy-Version (PWA): `scripts/assemble.py` → `docs/`, veröffentlichen mit `scripts/deploy.sh`

Kartendaten © OpenStreetMap-Mitwirkende (ODbL). Drehorte nach Mit Vergnügen, S-Bahn Berlin und yovie.
